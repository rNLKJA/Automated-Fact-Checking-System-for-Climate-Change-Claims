# web: Climate Claim Checker

The deployable Next.js 16 app (Vercel root directory). See the [root README](../README.md)
for the project overview and how `data/climate.db` is generated.

```bash
pnpm install
pnpm dev          # http://localhost:3309
pnpm lint         # ESLint
pnpm format:check # Prettier
pnpm typecheck    # next typegen && tsc --noEmit
pnpm test         # vitest: unit + parity tests against the original Python
pnpm build
```

| Path              | What lives there                                                                           |
| ----------------- | ------------------------------------------------------------------------------------------ |
| `src/app`         | Routes: `/`, `/try`, `/explore`, `/explore/[claimId]`, `/results`, `/method`, `/api/check` |
| `src/lib`         | Framework-free ports of the 2024 pipeline, each with vitest tests and fixtures             |
| `src/server`      | `server-only` repositories over the read-only SQLite file, and the Try-it pipeline         |
| `src/components`  | shadcn primitives (`ui/`), layout, evidence cards, charts                                  |
| `data/climate.db` | Generated by `../scripts/build_web_data.py`; opened read-only at runtime                   |

No environment variables are required.
